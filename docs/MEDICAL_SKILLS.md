# NanoClaw Container Agent Skills Reference

---

## General Tools

| Skill | Description |
|-------|-------------|
| agent-browser | Browse the web for any task — research topics, read articles, interact with web apps, fill forms, take screenshots, extract data, and test web pages. |
| find-skills | Helps users discover and install agent skills when they ask "how do I do X", "find a skill for X", or want to extend capabilities. |
| multi-search-engine | Multi search engine integration with 17 engines (8 CN + 9 Global). Supports Baidu, Bing, 360, Sogou, WeChat, Google, DuckDuckGo, WolframAlpha and more. No API keys required. |
| wikipedia-search | Search and fetch structured content from Wikipedia using the MediaWiki API. Supports multi-language queries. |

## Research & Literature

| Skill | Description |
|-------|-------------|
| academic-deep-research | Transparent, rigorous research with full methodology — mandated 2-cycle research per theme, APA 7th citations, evidence hierarchy, and 3 user checkpoints. |
| literature-manager | Search, download, convert, organize, and audit academic literature collections. Build libraries, download PDFs, convert to markdown, organize references. |
| arxiv-watcher | Search and summarize papers from arXiv. Use for latest research, specific topics, or daily summary of AI papers. |
| autonomous-research | Conduct comprehensive research independently — find information, analyze sources, synthesize findings, and create detailed reports without human guidance. |
| arxiv-cli-tools | arXiv CLI tools for paper search, download, and management. |
| baidu-scholar-search | Baidu Academic Search for Chinese and English literature, covering journals, conference papers, and dissertations. |
| pubmed-search | Search PubMed for scientific literature — find papers, search literature, look up research, find publications. |

## Medical Tools

| Skill | Description |
|-------|-------------|
| medical-research-toolkit | Query 14+ biomedical databases for drug repurposing, target discovery, clinical trials, and literature research. Access ChEMBL, PubMed, ClinicalTrials.gov, OpenTargets, OpenFDA, OMIM, Reactome, KEGG, UniProt and more. |
| medical-specialty-briefs | Generate daily or on-demand medical research briefs for any medical specialty. Searches top-tier journals (NEJM, Lancet, JAMA, BMJ, Nature Medicine). |
| medical-entity-extractor | Extract medical entities (symptoms, medications, lab values, diagnoses) from patient messages. |
| patiently-ai | Simplifies medical documents for patients — explains doctor's letters, test results, prescriptions, discharge summaries in clear, personalised language. |
| usmle | US medical licensing exam prep with progress tracking, weak area analysis, question bank management, and residency match planning. Covers Step 1/2 CK/Step 3. |
| biomcp-server | Biomedical MCP server integrating ClinicalTrials.gov, variant annotation (MyVariant), FDA drug data (OpenFDA), and literature (PubTator 3.0) in a unified query interface. |
| nutrigx_advisor | Nutrigenomics advisor — maps personal SNPs (MTHFR, MTR, etc.) to dietary recommendations based on risk alleles and published literature. |
