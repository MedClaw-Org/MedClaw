# NanoClaw 容器 Agent 技能手册

## 通用工具

| 技能 | 说明 |
|------|------|
| agent-browser | 浏览器自动化。可用于网页研究、阅读文章、与网页应用交互、填写表单、截图、提取数据、测试网页等。 |
| find-skills | 帮助用户发现和安装 Agent 技能。当用户询问"如何做 X"、"有没有能做 X 的技能"时触发。 |
| multi-search-engine | 多搜索引擎集成，支持 17 个引擎（8 个国内 + 9 个国际）。涵盖百度、Bing、360、搜狗、微信、Google、DuckDuckGo、WolframAlpha 等。无需 API Key。 |
| wikipedia-search | 通过 MediaWiki API 搜索并获取 Wikipedia 结构化内容。支持多语言查询。 |


## 研究与文献

| 技能 | 说明 |
|------|------|
| academic-deep-research | 透明、严谨的研究方法——每个主题强制 2 轮研究循环、APA 第 7 版引用、证据分级、3 个用户检查点。 |
| literature-manager | 学术文献管理——搜索、下载、转换、组织和审核文献集合。构建文献库、下载 PDF、转换为 Markdown。 |
| arxiv-watcher | 搜索和总结 arXiv 论文。适用于最新研究、特定主题或 AI 论文日报。 |
| autonomous-research | 自主进行综合研究——查找信息、分析来源、综合发现，生成详细报告，无需人工指导。 |
| arxiv-cli-tools | arXiv 命令行工具，用于论文搜索、下载和管理。 |
| baidu-scholar-search | 百度学术搜索工具，支持中英文文献检索，涵盖期刊论文、会议论文和学位论文。 |
| pubmed-search | 搜索 PubMed 科学文献——查找论文、搜索文献、查询研究、查找出版物。 |

## 医疗专用工具

| 技能 | 说明 |
|------|------|
| medical-research-toolkit | 查询 14+ 个生物医学数据库，用于药物再利用、靶点发现、临床试验和文献研究。通过统一 MCP 端点访问 ChEMBL、PubMed、ClinicalTrials.gov、OpenTargets、OpenFDA、OMIM、Reactome、KEGG、UniProt 等。 |
| medical-specialty-briefs | 按医学专科生成每日/按需医学研究简报。检索顶级期刊（NEJM、Lancet、JAMA、BMJ、Nature Medicine）最新研究。 |
| medical-entity-extractor | 从患者消息中提取医学实体——症状、药物、检验值、诊断等。 |
| patiently-ai | 为患者简化医疗文件——将医生信件、检查报告、处方、出院小结转化为清晰通俗的语言。 |
| usmle | 美国医师执照考试备考助手。提供进度追踪、薄弱点分析、题库管理和住院医匹配规划。涵盖 Step 1/2 CK/Step 3。 |
| biomcp-server | 生物医学 MCP 服务器，统一集成 ClinicalTrials.gov、变异注释（MyVariant）、FDA 药物数据（OpenFDA）和文献（PubTator 3.0）。 |
| nutrigx_advisor | 营养基因组学顾问——将个人 SNP（MTHFR、MTR 等）映射到基于风险等位基因和文献的膳食建议。 |
